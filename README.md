📧 Smart Email Summarizer (Local AI)

Privacy-first AI system for summarizing emails using a local LLM (Ollama)
No cloud • No data sharing • Fully local processing

🚀 Overview

Smart Email Summarizer (Local AI) is a full-stack application that summarizes emails, classifies urgency, extracts action items, and visualizes batch insights — all processed locally using a local Large Language Model.

✨ Features

📌 AI-generated email summaries

🚨 Urgency classification (Urgent / Important / FYI)

📝 Action item extraction

📊 Word count comparison (before vs after)

📂 Batch email processing (.txt files)

🔒 Privacy-first (no cloud APIs)

🛠️ Tech Stack

Frontend: React, Vite, Tailwind CSS, Recharts
Backend: Node.js, Express.js, Ollama (Local LLM)

▶️ Running the Project
1️⃣ Start Ollama
ollama run llama3.1:8b

2️⃣ Backend
cd backend
npm install
npm start

3️⃣ Frontend
cd backend/frontend
npm install
npm run dev
